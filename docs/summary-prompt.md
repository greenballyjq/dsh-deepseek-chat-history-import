# 摘要提示词：预设与自定义

摘要提示词只控制“摘要内容保留什么”。字数、纯文本和语言由宿主在生成时追加，用户不需要写 `{{limit}}`，写了也不会被替换。

## 预设

默认选中 **中性**：

| 预设 | 适合 |
|---|---|
| 中性 | 大多数对话：事实、决定、约束、未完成事项、重要结论 |
| 叙事 / 角色扮演 | 剧情、人物设定与关系、场景、偏好、未完成情节、梗 |
| 技术 / 工作 | 目标、约束、决策、代码/命令/配置、错误与修复、下一步 |

预设文本由面板在请求里直接发送；宿主不再按预设 id 去查文本。选中预设后，文本框显示该预设的完整文本，可直接改。

## 自定义

- 在文本框里编辑任意内容，下拉自动切到 **自定义**
- 自定义草稿在本次面板会话内保留；切到别的预设再切回自定义，草稿还在
- “恢复预设”回到最近一次选中的预设；默认是中性
- 自定义不能为空；最长 4000 字
- 切换文件/对话不会清空当前提示词；刷新页面重新从默认中性开始

## 我的预设

- 「保存为预设」把当前文本框内容保存成一个命名预设，出现在下拉的「我的预设」分组
- 内置预设（中性 / 叙事 / 技术）不能删除；选择内置预设时没有删除入口
- 选中「我的预设」后可删除；删除只影响这个自定义预设，不影响已导入会话
- 最多 20 个自定义预设，名称最长 40 字
- 编辑一个已保存的预设会切换到「自定义」，原预设保持不变；需要更新就重新保存（可再删除旧预设）
- 自定义预设保存在本机插件数据目录，不上传

## 宿主怎么拼装

生成摘要时，宿主发送的 system prompt 由固定开头 + 用户文本 + 固定输出约束组成：

- 固定开头说明任务是“把 DeepSeek 对话压缩成摘要”，输入按「用户—助手」轮次给出
- 中间是用户的额外要求（即上面的预设/自定义文本）
- 末尾是输出约束：只输出纯文本、不要标题/前言/套话、使用对话原本的语言、不超过本次摘要字数，并声明约束优先于用户要求

固定部分用户看不到，也不能编辑；即使用户写“写 5000 字”，也会被字数约束和宿主硬截断限制。

## 与费用预估的关系

自定义提示词会增加输入 tokens。费用预估按**实际拼装后的 system prompt** 计算，而不是固定按 300 tokens 估算；修改提示词时，预估会同步变化。

## 隐私

- 自定义提示词只随本次导入请求发送，不写入会话日志
- 会话旁的摘要记录只写提示词名称和短指纹，不写全文
- 不收集遥测；提示词只经 DSH 的模型服务使用
