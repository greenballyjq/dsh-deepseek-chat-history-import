# 版本 / 分支选择

DeepSeek 的对话是一棵树：同一条消息可能有多个重新生成/编辑出来的版本，后续内容也不同。

## 初始显示哪条

1. 如果导出里有「当前消息」标记：
   - 官方 v3：会话的 `current_message_id`
   - 旧版官方：没有该字段
   - 浏览器：`chat_session.current_message_id`
   用它
2. 没有标记：
   - 取**最新叶子**（消息时间最晚的那条分支）
   - 时间相同：取更长的那条链
   - 再相同：取偏好路径

新版官方导出带 `current_message_id`，默认就是导出时停留的那条；旧版官方没有这个标记，默认才是「最新」。

## 切换版本

选中某个版本后，往后走**内容最多的后续**（最长分支）。这是刻意的：

- 初始给你看当前/最新
- 想换版本时，看该版本最完整的那条后续

## 导入默认

「最后继续的版本」与初始规则相同：

- 有当前标记用标记
- 没有用最新叶子

「消息最多的版本」是最长分支。

## 自定义选择

- 「逐条选择版本」打开对话树视图
- 可以在任意一条消息上切换版本
- 选完后点「使用这个版本」，导入会使用该叶子
- 已选过版本后，设置里会显示「已选：…」和「重选」；重选会停在上次选的位置

## 不会做什么

- 不把两个版本的消息拼接
- 不按标题或长度猜「哪个是用户想要的」
- 不会因为某个分支短就丢弃它；选择权在你
